Sistemas de Aprendizaje Automático · Caso 5

SonríeValencia

Preparación y transformación de datos para anticipar las ausencias de pacientes a sus citas dentales.

Objetivo: convertir los datos históricos en un conjunto preparado para un futuro modelo de clasificación.

Punto 1 · Comprensión del problema

¿Qué problema queremos resolver?

SonríeValencia dispone de tres clínicas dentales que quieren reducir las ausencias de sus pacientes.

3

Clínicas dentales

45 min

Tiempo aproximado perdido por cada ausencia

1 día

Antelación prevista para realizar las llamadas

Objetivo empresarial

Identificar qué pacientes tienen mayor probabilidad de no acudir para priorizar las llamadas de recordatorio.

Objetivo técnico

Preparar un conjunto de datos limpio y utilizable para entrenar posteriormente un modelo de clasificación binaria.

Decisión importante: cada fila representa una cita, no necesariamente un paciente diferente. La variable que queremos predecir es no_acude.

Proceso de carga y revisión

  • Se importó sonrievalencia_citas.csv utilizando el separador punto y coma.

  • 65 valores de seguro tenían espacios al principio o al final.

Tratamiento aplicado

  • Se normalizaron los textos y las categorías.
  • Se trataron los valores ausentes con criterios de imputación.
  • Se revisaron los valores extremos y las inconsistencias temporales.
  • Se distinguieron los valores desconocidos de las respuestas negativas reales.
Punto 5 · Transformación de datos

Convertir la información en variables utilizables

Se transformaron las variables para que pudieran ser utilizadas por algoritmos de aprendizaje automático.

Codificación

  • Las variables binarias se representaron mediante valores 0 y 1.
  • Las categorías de clínica, seguro y tratamiento se transformaron mediante variables dummy.
  • La edad se agrupó en cuatro tramos.

Menor

Hasta 18 años

Joven

De 19 a 35 años

Adulto

De 36 a 60 años

Senior

Más de 60 años

Nuevas variables derivadas

  • dias_antelacion: tiempo entre la reserva y la cita.
  • dia_semana_cita: día de la semana de la cita.
  • es_tarde: indica si la cita pertenece a la franja de tarde.
  • miedo_dentista: indicador derivado de la información disponible en las notas.
  • tiene_nota: indica si existe una nota de recepción.
Justificación: estas transformaciones permiten representar mejor la información y facilitar que un futuro modelo encuentre patrones.

Conclusión

¿Qué hemos conseguido?

El proyecto permitió transformar un conjunto de datos operativo de citas dentales en una estructura numérica y preparada para el aprendizaje automático.

  • Se analizaron 2.400 citas y 19 variables originales.
  • Se identificaron problemas de calidad y se aplicaron tratamientos.
  • Se codificaron las variables y se generaron nuevos atributos.
  • Se eliminaron identificadores y columnas redundantes.
  • Se generó un CSV final con 2.400 filas, 37 columnas y sin valores nulos.
  • Se preparó una partición de entrenamiento y prueba para una futura fase de modelado.

Mensaje final

El objetivo no era simplemente limpiar un archivo, sino preparar datos fiables para ayudar a las clínicas a anticipar las ausencias, organizar mejor su actividad y reducir el tiempo de consulta perdido.
